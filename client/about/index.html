About the data

MODIS and VIIRS both detect heat from orbit. Their pixel sizes and observation times differ, so the same fire can look different in each dataset.

MODIS vs. VIIRS

NASA FIRMS publishes active-fire detections from both instruments. The nominal pixel sizes below describe the detection products near the point directly beneath the satellite.

MODIS 1 km

Moderate Resolution Imaging Spectroradiometer

Flown on Terra and Aqua, MODIS provides a long record of fire observations. One larger pixel can contain several nearby hotspots.

VIIRS 375 m

Visible Infrared Imaging Radiometer Suite

Flown on satellites including Suomi NPP and NOAA-20, VIIRS can detect smaller fires and distinguish hotspots that may fall within the same MODIS pixel.

Squares compare nominal pixel widths at the same scale. A detection identifies a pixel containing a heat source. The fire may occupy only a fraction of that pixel.

Why timing matters

Polar-orbiting satellites observe a location as they pass overhead. A fire can change between passes, so differences can reflect the time of observation as well as the instrument. Clouds can also block a detection.

The explorer starts in UTC, a shared clock for comparing acquisition times across locations. Local solar analysis uses each detection’s longitude to estimate the local mean solar time, which helps compare the same part of the day across regions.

Choose Selected 24 hours or Entire file to set the time range. Playback advances in 15-minute steps and shows detections from the preceding 60 minutes. The full-range view shows all matching detections in the chosen range.

How to read the explorer

Fire radiative power (FRP)
An estimate of the rate at which a fire emits radiant energy, measured in megawatts (MW). The explorer uses FRP to color the markers. Points use a small, fixed screen size for readability; color shows FRP. Select a point or an observation record to inspect its values. Point size does not describe the fire perimeter.
Raw MODIS and Raw VIIRS
These layers show detections labeled for each sensor using their stored raw FRP values. Imported MODIS files contain MODIS detections only. The hotspot count counts visible records, and one fire can have several detections.
AI Harmonized
This layer shows precomputed sample estimates that illustrate how measurements from different sensors and overpass times might be made easier to compare. The explorer displays stored values and does not run a model.
Export data
Downloads the currently filtered records as GeoJSON, including coordinates, sensor label, acquisition time, local solar time, confidence, and FRP values.
Check the data source. Prometheus can show a demonstration dataset, an imported MODIS snapshot, or published harmonized estimates from the data team. The sidebar identifies the active source. For current active-fire data, use NASA FIRMS.
